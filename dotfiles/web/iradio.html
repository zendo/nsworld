    关于 iRadio

    单文件网页版网络电台播放器，数据来自 Radio Browser API。

    与 Qt 版 BearWave 的差距：

    • 曲目元数据（ICY）依赖流服务器开放 CORS，多数电台拿不到
    • 没有系统托盘、后台常驻、MPRIS 名称与开机自启
    • https 页面无法播放 http 流（混合内容拦截）
    • HLS（.m3u8）在 Chrome / Edge 142+ 与 Safari 原生可播，Firefox 桌面不行

    建议用 python3 -m http.server 本地启动，这样能播放 http 电台。
    导入 / 导出
    导出格式与原生 BearWave 一致：JSON 数组，每项 uuid name url urlResolved country，按名称排序。 直接覆盖到 ~/.config/bearwave/favorites.json 即可（Flatpak 为 ~/.var/app/de.nerdbear.bearwave/config/bearwave/）。
